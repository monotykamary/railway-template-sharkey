# Sharkey on Railway

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/sharkey?referralCode=ZqgrJ0)

Deploy Sharkey 2025.4.7 with a generated root password, private PostgreSQL and authenticated Redis, persistent media, closed first-run setup, and daily backups.

Sign in as `admin` with `SHARKEY_ADMIN_PASSWORD`. Use one application replica because media uses an attached volume.
